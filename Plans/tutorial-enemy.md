# 序章教学敌人设计方案（tutorial-enemy）

> 状态：定案 + C++ 落地完成（2026-08-09）；编辑器侧资产由用户手动完成
> 关联文档：GDD_Outline.md v0.26、DataTable_Spec.md v0.20、DevLog.md（2026-08-09 策划）

## 1. 定案摘要

1. 新增 `DT_EnemyConfig` 行 `apprentice_cave`（低级魔法师·序章教学版），不复用 `apprentice` 行。
2. 洞穴只有这一场教学战斗；`inept`（无能力者）移除洞穴，仅保留小镇外围。
3. 教学 1 一次性完成全部教学：红蓝白三色克制、金色反击、蓄力、同色碰撞、实时格挡/闪避；取消教学 2。
4. 教学战无掉落：烟只在击败敌人时掉落；魔法师为逃跑方，不掉学徒之烟。
5. 序章剧情改为主角 Dale 暗处发现低级魔法师并突袭 → 玩家先制。

## 2. 开场与先制设计

- 过场：Dale 在暗处发现低级魔法师（观察 → 突袭），随后进入教学战。
- 玩家先制效果（GDD §5.2.1 定案）：与敌方先制效果一致——玩家 1 层蓄力、敌方 0 层（开局 1:0），无其它效果（无先制伤害、无首回合禁蓄力）。
- 实现：`UBattleComponent::EnterBattle` 增加玩家先制分支（当前仅 `bEnemyFirstStrike`）。

## 4. 教学引导（自由战斗 + 条件教学点）

开局：玩家 1 层蓄力（玩家先制）、敌方 0 层。除两个条件教学点外，玩家自由出招、敌方随机 AI（`UEnemyCombatAIComponent`），不再有固定回合脚本。

| 引导事件 | 触发条件 | 内容 |
|----------|----------|------|
| 开场总提示（一次） | 进入战斗后、玩家首次选择行动前 | "触发先制攻击可以在战斗开始时直接获得一层蓄力，蓄力层数最高两层，拥有蓄力层数可以使用蓝色攻击，蓝色攻击克制白色攻击，白色攻击克制红色防御，红色防御克制蓝色攻击" |
| 教学点 A：满蓄破红防 | 玩家蓄力 1 层（首回合除外）且未演示过 | 敌方强制红防 + 锁定玩家蓄力；提示"使用蓄力使蓄力层数到达上限，若敌方此时使用红防，则会在完成蓄力后自动对敌方使用蓄力攻击" |
| 教学点 B：蓄力抵抗白攻 | 玩家蓄力 0 层且未演示过 | 敌方强制白攻 + 锁定玩家蓄力；提示"使用蓄力使蓄力到达一层时，若敌方使用白攻，则我方减少受到伤害并获得额外回合" |
| 白攻碰撞（首次） | 玩家在自由回合第一次选择白攻 | 敌方必定同步白攻（覆盖已选行动），触发白白碰撞；碰撞阶段显示格挡/闪避提示 |
| 额外回合 | 玩家获得额外回合 | 提示"额外回合：只能选择蓝攻或蓄力！"（不锁定，按标准规则开放蓝攻/蓄力） |
| 碰撞提示 | 触发同色碰撞（蓝蓝/白白） | "双方使用相同的攻击触发对拼，需要在敌方攻击将要击中的时候点击E格挡/Shift闪避，格挡成功可以造成反击" |

### 4.1 条件教学点校验（对齐战斗规则 v1.1）

- 教学点 A（P=1）：玩家蓄力 1→2；敌方红防被自动强化蓝攻破防（先蓄力动画再接蓝攻，2.25 倍蓝伤），P 结算 1 层（2→0→+1）。
- 教学点 B（P=0）：玩家蓄力 0→1；敌方白攻被抵抗（0.3 倍伤），P 获得 1 层 + 额外回合；白攻方清空自身层数且无蓄力奖励。
- 额外回合仅蓝攻/蓄力：蓝攻结算后回到 1 层，蓄力则到 2 层（后续回合均合法）。
- 白攻/红防每次使用都会清空自身蓄力层数（含红红跳过），教学点回合结束后敌方层数自然归位，下一回合回落随机 AI。
- 两个教学点都演示过后，敌方血量 ≤ `RunAwayHPThreshold`（0.3）触发逃跑；15 回合上限兜底防软锁。

### 4.2 容错设计

- 敌方伤害倍率 0.4，错误操作只吃少量伤害；连续 3 次错误不致死。
- 教学点锁定仅限"蓄力"按钮（`PlayerChooseAction` 逻辑层同步拒绝），其余回合自由选择。
- 教学点由玩家层数条件触发：玩家到达 0 层 / 1 层（首回合后）即必然演示；若一直未触发，15 回合兜底逃跑，不会卡死。

### 4.3 条件锁定（2026-08-09）

教学战**不再逐回合锁定按键**；仅两个教学点回合把玩家锁定为蓄力，其余回合四个行动按钮按标准规则开放。

- 实现：`UBattleComponent` 教学导演（`UpdateTutorialDirector`：覆盖敌方行动 + 设置 `bTutorialChargeLockActive` + 提示文字）+ `GetTutorialLockedPlayerAction()` 返回蓄力 + HUD 按钮状态。
- 额外回合不锁定（按标准规则仅蓝攻/蓄力）；锁定行动非法（蓄力已达上限）时自动解锁兜底。

### 4.4 同色碰撞可格挡慢放（2026-08-09）

- 仅序章教学战生效（`IsTutorialBattle()` 门控，正式战斗不改时间流速）：同色碰撞进入可格挡窗口时，世界时间流速降至 `ClashTimeDilation`（默认 0.05，`[PLAYTEST]`，0=关闭）。
- 玩家点击格挡或闪避后立即恢复正常；碰撞结算/战斗清理/失败重开兜底恢复。
- 慢放起点 = 命中时间 − `min(格挡窗, 闪避窗)`：慢放出现时格挡/闪避窗口均已开放，立即点击按原 Elapsed 窗口判定即成功（不修改输入判定逻辑）。
- 判定窗口时长仍按世界时间计算——慢放只延长真实反应时间，不改变判定公平性（0.05 ≈ 时停，若出现计时/表现问题可改为完整时停）。
- 实现：`UBattleComponent::ApplyClashTimeDilation` / `RestoreTimeDilation`，参数在 `DT_CombatParams`。

## 5. 逃跑与门扉

- 逃跑触发：两个蓄力教学点（A/B）均演示后，敌方血量 ≤ `RunAwayHPThreshold`（0.3）触发逃跑；15 回合上限兜底，避免教学点因玩家层数状态迟迟未触发导致软锁。
- 锁血 1：教学期间魔法师不可被击杀。
- 演出：逃跑 → 魔法门过场 → 主角跟随穿越门扉（Level Sequence）。
- 战斗清理复用现有链路：`SheathePlayerWeapon`（收刀/停 Montage/清定时器）。

## 6. 掉落与烟

- 教学战无掉落（无学徒之烟、无货币），保持"烟仅在击败敌人时掉落"语义一致。
- 首次获得烟引导（FTUE [12-14 分钟]）移至小镇第一场战斗掉落，属后续内容任务，不阻塞本敌人。

## 8. 验收标准

- 全新存档一次教学战完成全部机制教学（目标 ≤6 分钟）。
- 玩家先制生效：开局玩家 1 层、敌方 0 层，与敌方先制机制一致，无其它效果。
- 引导式教学无卡死；两个教学点必然演示；错误操作只吃少量伤害，3 次错误不致死。
- T7 蓝蓝碰撞必触发，格挡/闪避窗口正常；碰撞后 100% 逃跑，门扉衔接正常。
- 魔法师不可被击杀；战斗清理（收刀/停 Montage/清定时器）无残留。
- 洞穴无其他敌人；序章仅第 0 次轮回；Satan 战回归不受影响。
- 每次 C++ 改动后立即编译通过（Build.bat，内存压力时 `-NoUba`）。
